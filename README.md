## Запуск локально

Клонируйте репозиторий:
   ```bash
   git clone https://github.com/AlexFrankiv/java-project-72.git
   cd java-project-72/app
```
Соберите и запустите:
``` bash
./gradlew run
```
Приложение будет доступно по адресу http://localhost:7070
